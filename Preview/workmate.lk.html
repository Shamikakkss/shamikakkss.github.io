Core System Capabilities

Engineered for transparent job dispatching, real-time navigation, and skilled worker collaboration

SOS / Emergency Job Dispatch

Tag critical tasks like electrical short circuits or pipe leaks as EMERGENCY to broadcast priority alerts to all nearby active workers.

GPS Navigation & Map Pinning

Clients drop precise location pins on interactive Leaflet maps while workers view real-time distance and turn-by-turn navigation routes.

Live Status Stepper

Real-time progress tracking pipeline updating both Client & Worker: Job Posted ➔ Worker Assigned ➔ On The Way ➔ Work Started ➔ Completed.

In-App Chat & Direct Call

Direct real-time messaging, click-to-call direct phone dialer, and instant message launching for smooth coordination once a job is accepted.

Clerk Multi-Role Security

Secure identity management supporting CLIENT, WORKER, EMPLOYER, and ADMIN roles with metadata sync.

Neon Serverless Database

High-performance serverless PostgreSQL relational database managed via Prisma 6 ORM with SSL encryption and connection pooling.
