Core System Capabilities

Engineered for end-to-end design ordering, payment verification, and client collaboration

EmailJS OTP Authentication

Secure user registration featuring real-time username uniqueness validation, profile image compression, and 6-digit OTP verification sent via EmailJS.

Dual Payment Engine

Integrated with PayHere Sri Lanka LKR gateway via server-side Supabase Edge Function hashes, plus manual bank slip upload with admin review portal.

Real-Time Messaging

Per-order chat channels and general support messaging powered by Firestore onSnapshot listeners with full image attachment support.

Live Order Lifecycle Stepper

Transparent 6-stage order tracking pipeline: Order Placed ➔ Payment Accepted ➔ Design in Progress ➔ Files Delivered ➔ Completed ➔ Review Posted.

Photopea Editor Integration

Admin panel features a 1-click launcher into Photopea web editor, recording start timestamps and streamlining graphic design creation directly in-browser.

1-Click Bulk Delivery (JSZip)

Admin uploads multi-file deliverables to Supabase Storage; clients download individual files or compress all assets into a single `.zip` file using JSZip.
